# JobLens Demo Script

1. Register a candidate account.
2. Upload a PDF or DOCX resume.
3. Poll `/api/resumes/status` until `PROFILE_EXTRACTED`.
4. Open the recommended jobs view.
5. Open a match analysis and explain the score formula.
6. Show matched skills, missing evidence, and resume citations.
7. Save a job and mark it as applied.
8. Ask the assistant which resume evidence supports the selected role.
9. Open Swagger UI to demonstrate the API contract.
10. Show the ranking evaluation endpoint and explain Precision@K, Recall@K, and NDCG@K.
